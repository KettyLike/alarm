# Air Alert Monitor

Локальний Python-застосунок, який читає повідомлення з Telegram-каналів через user API, знаходить назви населених пунктів, рахує відстань до заданої точки та подає локальний сигнал.

Застосунок не вимагає, щоб тип загрози та населений пункт були в одному повідомленні. Він зберігає контекст останніх повідомлень у пам'яті процесу та об'єднує reply-ланцюжок до 10 повідомлень у межах `MESSAGE_CONTEXT_MINUTES`.

## 1. Встановлення

Потрібен Python 3.11 або новіший. Якщо команда `py` не знайдена, встановіть Python з `python.org` і під час інсталяції увімкніть `Add Python to PATH`. Після встановлення відкрийте нове вікно PowerShell.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
Copy-Item .env.example .env
```

## 2. Перша перевірка без Telegram

```powershell
py app.py --test-message "БПЛА летить на Фастів"
```

Для Києва Фастів буде показаний приблизно за 55 км, тому при радіусі 40 км сигнал не спрацює. Перевірте тригер так:

```powershell
py app.py --test-message "БПЛА летить на Київ"
```

## 3. Налаштування Telegram

1. Створіть application на `my.telegram.org` і отримайте API ID та API hash.
2. Заповніть у `.env` `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` і `TELEGRAM_CHANNELS`.
3. У `TELEGRAM_CHANNELS` вкажіть username каналів через кому, наприклад `@channel_one,@channel_two`. Також можна використовувати повне посилання `https://t.me/channel` або numeric ID. Відображувана назва каналу, наприклад `Kyiv AirDefense`, не підходить.
4. Запустіть `py app.py`. Перший запуск попросить телефон, код Telegram і пароль 2FA.

Щоб додати ще один канал, перелічіть канали через кому:

```env
TELEGRAM_CHANNELS=https://t.me/kyiv_airdef,@другий_username
```

Кожен канал має бути доступний вашому Telegram-акаунту, під яким працює Telethon. Після зміни `.env` перезапустіть програму.

У `.env` параметр `MESSAGE_CONTEXT_MINUTES=20` визначає, як довго пам'ятати пов'язані повідомлення. Кулдаун між сповіщеннями вимкнено: кожна нова знайдена локація одразу надсилає alert. Наприклад, повідомлення `Повітряна ціль` і відповідь `на Бучу` будуть оброблені разом. Повідомлення з назвою району або міста також обробляються без ключових слів `БПЛА` чи `ракета`.

### Сповіщення на телефон

1. У Telegram відкрийте `@BotFather`, виконайте `/newbot` і скопіюйте токен.
2. Відкрийте створеного бота та надішліть йому `/start`.
3. Дізнайтеся свій `chat_id` через `https://api.telegram.org/bot<TOKEN>/getUpdates` або окремого бота для показу ID.
4. Додайте в `.env`:

```env
TELEGRAM_BOT_TOKEN=123456:your_bot_token
TELEGRAM_ALERT_CHAT_IDS=123456789,987654321
```

Після цього застосунок надсилатиме кожен alert у всі перелічені чати й паралельно подаватиме локальний звук, якщо `ALERT_SOUND=true`. Використовується тільки параметр `TELEGRAM_ALERT_CHAT_IDS`. Не публікуйте токен бота.

Для сповіщення всіх підключених людей зручніше створити Telegram-групу, додати туди людей і бота, а потім вказати один `chat_id` цієї групи. Усі учасники групи отримуватимуть повідомлення. Бот має бути доданий до групи та мати право надсилати повідомлення.

Для наскрізного тесту без очікування повідомлення з каналу виконайте:

```powershell
python app.py --test-message "Небезпека біля Києва"
```

У результаті має прийти повідомлення від вашого бота. Якщо локація поза `ALERT_RADIUS_KM`, використайте для тесту тимчасово більший радіус, наприклад `ALERT_RADIUS_KM=140`.

Файл `*.session` є секретним: не передавайте його іншим і не додавайте до Git.

Якщо з'являється `sqlite3.OperationalError: database is locked`, зупиніть усі попередні запуски `app.py` через `Ctrl+C`. Перевірте `Get-Process python`. Коли Python-процесів не залишилося, видаліть тільки `air_alert_session.session-journal` і запустіть `python app.py` один раз. Файл `air_alert_session.session` не видаляйте, інакше доведеться авторизуватися в Telegram повторно.

## 6. Розгортання на Railway

Railway запускає цей проєкт як worker-процес, тому відкритий HTTP-порт не потрібен.

1. Створіть приватний GitHub-репозиторій і завантажте код. Не завантажуйте `.env`, `*.session` або токени.
2. У Railway створіть **New Project** -> **Deploy from GitHub Repo** і виберіть репозиторій.
3. У сервісі відкрийте **Variables** і додайте всі змінні з `.env.example` зі своїми значеннями. Мінімально потрібні `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_CHANNELS`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALERT_CHAT_IDS`, `USER_LAT`, `USER_LON`, `ALERT_RADIUS_KM` і `ALERT_SOUND=false`.
4. Додайте **Volume** до сервісу та змонтуйте його в `/data`.
5. У Variables задайте `TELEGRAM_SESSION=/data/air_alert_session`. Це збереже Telegram-авторизацію між перезапусками.
6. У **Deploy** перевірте Start Command: `python app.py`. Ця команда вже записана в `railway.toml`.
7. Відкрийте **Logs**. Успішний запуск має містити `Telegram-клієнт запущений`.

Першу авторизацію Telethon зручніше виконати локально, а потім перенести створений `air_alert_session.session` у Volume Railway через Railway Shell. Якщо авторизація на сервері попросить код, введіть його лише в приватній Shell-сесії Railway.

Railway має платні ресурси та може зупинити сервіс через відсутність балансу. Для постійного моніторингу перевірте тариф і ліміти перед запуском. Локальний `winsound` на Railway не працює, тому використовуйте `ALERT_SOUND=false` і Telegram-сповіщення.

Це інформаційний інструмент, а не заміна офіційних сповіщень цивільного захисту. Координата населеного пункту є приблизною оцінкою, а не точною позицією повітряної цілі.
